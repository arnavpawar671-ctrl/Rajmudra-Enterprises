Rajmudra Enterprises — static HTML/CSS website
=============================================

Files
-----
index.html    Full single-page website (all sections)
styles.css    All styling (dark navy + gold theme, responsive)
script.js     Mobile menu toggle + footer year
images/       All photos, brand mark, full logo, social preview image
favicon.png   Browser tab icon
robots.txt    Search engine instructions

How to use
----------
1. Open index.html in any browser to view locally.
2. To publish: upload ALL files and the images/ folder to your web host
   (e.g. cPanel public_html, Hostinger, GoDaddy, Netlify drag-and-drop).
3. Keep the folder structure exactly as it is so images keep working.

Editing tips
------------
- Text, phone numbers, addresses, bank details: edit index.html.
- Colours and fonts: edit the variables at the top of styles.css.
- Replace an image: drop a new file into images/ with the same filename.

No build tools, frameworks or internet connection required (fonts load from
Google Fonts; the site still works without them using system fonts).


Updated service imagery uses externally hosted real product/installation photos for Fire Alarm, Access Control and Flap Barrier Turnstile, plus an integrated security control-room hero image.
